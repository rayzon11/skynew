## Stack and commands

This is a static HTML/CSS/JavaScript website, with a small Node.js generator. No npm install, framework migration or production Node server is needed.

- `node package.mjs`: regenerate HTML/catalogue and run existing verification. This does not create a ZIP.
- `node server.mjs`: serve `dist` at http://127.0.0.1:4277/.
- `node --check dist/app.js`: check interaction script syntax.
- Deployable files are the contents of `dist`, including `.htaccess`.

Important: `dist/casino.css`, `dist/app.js`, `dist/404.html`, `dist/.htaccess` and assets are maintained source files even though they are inside `dist`. `dist/styles.css`, `dist/theme-warm.css` and `dist/scene.js` are the previous design, no longer loaded by index.html, kept for reference. Do not delete or clean this directory. Only `dist/index.html` and `dist/catalogue.json` are regenerated by `build.mjs`.
